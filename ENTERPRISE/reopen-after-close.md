# Reopen after closeout (no prices)

This page lists how a **closed engagement** may start again. It is not a warranty claim, not a ticket SLA, and not a claim that any closed engagement already exists.

Companions: [`order-and-contract.md`](order-and-contract.md), [`engagement-closeout.md`](engagement-closeout.md), [`records-retention.md`](records-retention.md), [`correction-notice.md`](correction-notice.md), [`inquiry-completeness.md`](inquiry-completeness.md), [`well-being-alignment.md`](well-being-alignment.md).

## When this page may be used

Only after:
1. The six completeness items were present.
2. A quote following the ten-section outline existed off-repo.
3. The buyer accepted that quote in writing.
4. A packet cover sheet exists.
5. Open change orders were accepted or declined.
6. A closeout note exists.
7. A retention note exists that names keep vs discard.

Until those seven are true, the next action is still questions, a quote, a packet, a change order, closeout, retention, or a correction notice — not a reopen.

A reopen is a *new inquiry*. It is **not** a correction notice and **not** a silent change order on a closed file list. New models, new energy rows, or new deliverable shapes must re-run [`inquiry-completeness.md`](inquiry-completeness.md).

## What a reopen note must name

| Field | Rule |
| --- | --- |
| Prior closeout id | Off-repo label only; do not invent a public case id |
| Why reopen | `new-scope` / `new-measurement` / `new-site` / `undecided` |
| Models requested now | Public numbers or `NN-custom-<slug>` ancestry |
| Energy-honesty rows | Fresh marks; do not copy `agreed` from the closed packet unless still true |
| Relation to correction | If the only issue is a typo in a named file, use [`correction-notice.md`](correction-notice.md) instead |
| Commercial figure | Written only on the off-repo quote after the new gate — never on this page |

## Allowed reopen classes

- Request an additional model number that was out of scope on the closed packet.
- Restart measurement rows that closeout left as `to-be-measured`.
- Move from research-replica to field-customization after the first packet is closed.
- Name a different site or air-gap constraint than the closed packet used.

## Forbidden reopen classes (on this page and in cover letters)

- Relabeling the closed packet as still open so a change order can skip completeness.
- Treating a correction notice as if it added new deliverables.
- Publishing buyer names, logos, or prices in the public tree.
- Claiming Models 19–22 gates became certified because an engagement reopened.
- Inventing a prior customer or a measured MTBF to justify the reopen.

See [`well-being-alignment.md`](well-being-alignment.md).

## Maintainer fill order

1. Confirm closeout and retention notes exist.
2. Refuse to treat the request as a correction if new files or new energy rows are involved.
3. Ask the six completeness items again.
4. Only after the gate, write a new quote using [`quote-draft-outline.md`](quote-draft-outline.md).

No prices, customers, or SLAs are added by this page.
