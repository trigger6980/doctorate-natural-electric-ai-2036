# Allowed cover-letter claims (no prices)

Use this page when drafting the short cover block that sits above a quote outline. It is not a marketing brochure and not a rate card. Companion files: [`quote-draft-outline.md`](quote-draft-outline.md), [`engagement-faq.md`](engagement-faq.md), [`placeholder-engagement-tiers.md`](placeholder-engagement-tiers.md), [`well-being-alignment.md`](well-being-alignment.md), [`licensing-boundary.md`](licensing-boundary.md).

## Sentences that are allowed
Copy only if the public tree still supports them:

- Energy state is a first-class refuse signal on the host sketches in this repository.
- Public model cards are interface contracts; ancestry numbers stay visible on custom variants (`NN-custom-<slug>`).
- Operator AI pieces here are host sketches: task graphs, policy gates, and JSON checkpoints a buyer can read.
- Off-grid and low-power sites are first-class contexts for Natural Electric + Future AI human well-being.
- A complete inquiry is required before any written quote. Incomplete packets receive questions, not numbers.
- Placeholder engagement tiers name *shapes of work*, not fees.

## Sentences that are forbidden until STATUS.md says otherwise
- Any dollar amount, “starting at”, retainer, or SLA.
- Measured MTBF, COP, joules-per-step, or field certification.
- Customer names, logos, or implied revenue.
- Treating host fixture walks as analog, materials, radio, or motion certificates.
- Treating any `*_ok` helper as a plant-safety certificate.

## How a maintainer uses this page
1. Draft the cover from the allowed list only.
2. Attach one placeholder tier name from [`placeholder-engagement-tiers.md`](placeholder-engagement-tiers.md).
3. Add the matching model-gate footnotes.
4. Leave every money field blank.
5. If the buyer asks for a claim not listed here, refuse the sentence rather than inventing a sixth value proposition.
