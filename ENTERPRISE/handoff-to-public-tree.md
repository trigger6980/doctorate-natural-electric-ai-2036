# Handoff to the public tree (no prices)

This page lists when the honest next step is **study the public repository**, not a quote. It is not a rejection score, not a ticket SLA, and not a claim that any inquiry has already been handed off.

Companions: [`order-and-contract.md`](order-and-contract.md), [`decline-or-defer.md`](decline-or-defer.md), [`inquiry-completeness.md`](inquiry-completeness.md), [`inquiry-response-template.md`](inquiry-response-template.md), [`licensing-boundary.md`](licensing-boundary.md).

## When this page may be used

After an inquiry or informal question exists. A public-tree handoff is a *scope-honesty decision*: the sender already has what they asked for under the public licenses.

Until the six completeness items exist, questions remain the default. A handoff is appropriate when the request is already answered by a public card, host test, or licensing page — not when energy rows are merely unlabeled.

A handoff is **not** a decline with prejudice, **not** a packet, and **not** a closeout. A later contract request must start as a new inquiry (or a reopen if a prior closed packet exists).

## What a handoff note must name

| Field | Rule |
| --- | --- |
| Inquiry reference | Off-repo label or GitHub issue number only; do not invent a public case id |
| Decision | `handoff-public` / `undecided` |
| Why | `already-public` / `study-first` / `no-private-object` / `other` |
| Pointers | Exact public paths the sender should read |
| Commercial figure | None. A handoff does not include a price |

## Allowed handoff classes

- The sender asked for a model card, interface table, or host test that is already in the public tree.
- The sender asked whether they may *read and study* the catalog; that is already covered by [`licensing-boundary.md`](licensing-boundary.md).
- The requested “deliverable” is a public README or STATUS line, not a private pack.
- The work is better done as public-tree study before any identical/custom delivery is discussed.

## Forbidden classes (on this page and in cover letters)

- Using a handoff to hide a decline that should follow [`decline-or-defer.md`](decline-or-defer.md).
- Inventing a waitlist, queue length, or “come back after N days” SLA.
- Attaching a placeholder price to a handoff.
- Claiming Models 19–24 became certified because a reader was pointed at the public card.
- Treating a handoff as if a packet or change order already exists.

See [`well-being-alignment.md`](well-being-alignment.md).

## Maintainer fill order

1. Name the public paths that already answer the question.
2. Say whether a later `enterprise-inquiry` would still make sense (private pack, measured joules, Operator AI integration).
3. Do not write a quote after a handoff. If the sender later needs private objects, they re-enter [`inquiry-completeness.md`](inquiry-completeness.md).

No prices, customers, or SLAs are added by this page.
