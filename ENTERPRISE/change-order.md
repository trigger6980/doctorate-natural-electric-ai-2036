# Change order after packet (no prices)

This page lists how a **scope change** is recorded after a packet assembled from [`post-quote-packet.md`](post-quote-packet.md) exists. It is not a shipping SLA, not a checkout, and not a claim that any change order has already been issued.

Companions: [`order-and-contract.md`](order-and-contract.md), [`quote-draft-outline.md`](quote-draft-outline.md), [`post-quote-packet.md`](post-quote-packet.md), [`inquiry-completeness.md`](inquiry-completeness.md), [`licensing-boundary.md`](licensing-boundary.md), [`well-being-alignment.md`](well-being-alignment.md).

## When this page may be used

Only after:
1. The six completeness items were present.
2. A quote following the ten-section outline existed off-repo.
3. The buyer accepted that quote in writing.
4. A packet cover sheet exists (public vs private files named).

Until those four are true, the next action is still questions, a quote, or a packet — not a change order.

## What a change order must name

| Field | Rule |
| --- | --- |
| Trigger | Buyer request, measurement result, or discovered out-of-scope file |
| Model numbers | Copied from the accepted quote, plus any new ancestry ids |
| Identical vs custom | Re-stated; moving identical → custom is itself a change |
| Energy-honesty rows | Which rows stay agreed / move to to-be-measured / move out of scope |
| Files added or removed | Each marked public-tree copy vs private |
| Transfer method | Unchanged unless the change explicitly switches air-gap vs private repo |
| Commercial figure | Written only on the off-repo change document — never on this page |

## Allowed change classes

- Add a model number that was listed as ancestry-only.
- Move a measurement row from out-of-scope to to-be-measured (buyer lab or joint).
- Swap transfer method (air-gap media ↔ private repo) without adding telemetry.
- Replace a private file with a newer snapshot of the same object.

## Forbidden change classes (on this page and in cover letters)

- Adding prices, SLAs, or customer logos to the public tree.
- Relabeling host sandbox logs as field certificates.
- Quietly treating cards 02–18 as licensed weight files.
- Inventing radio, coil, piezo, photodiode, TPM, or schema-compiler deliverables that the quote did not name.

See [`well-being-alignment.md`](well-being-alignment.md).

## Maintainer fill order

1. Copy the accepted quote sections that still hold.
2. List only the rows that change; do not rewrite unchanged energy marks.
3. Re-issue the packet cover sheet with the new file list.
4. Do not start the new work until the change is accepted in writing.

No prices, customers, or SLAs are added by this page.
