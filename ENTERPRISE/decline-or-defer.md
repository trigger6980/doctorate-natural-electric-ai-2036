# Decline or defer (no prices)

This page lists how the maintainer may **decline** or **defer** an inquiry. It is not a capacity metric, not a ticket SLA, and not a claim that any inquiry has already been declined.

Companions: [`order-and-contract.md`](order-and-contract.md), [`inquiry-completeness.md`](inquiry-completeness.md), [`inquiry-response-template.md`](inquiry-response-template.md), [`well-being-alignment.md`](well-being-alignment.md), [`reopen-after-close.md`](reopen-after-close.md).

## When this page may be used

After an inquiry exists (complete or incomplete). Decline/defer is a *maintainer decision about scope honesty*, not a ranking of the buyer.

Until the six completeness items exist, the usual next action is still questions — not a decline that pretends the inquiry was evaluated as a quote.

A decline is **not** a correction notice and **not** a closeout. No packet is implied. A later request must start as a new inquiry (or a reopen if a prior closed packet exists).

## What a decline or defer note must name

| Field | Rule |
| --- | --- |
| Inquiry reference | Off-repo label or GitHub issue number only; do not invent a public case id |
| Decision | `decline` / `defer` / `undecided` |
| Why | `out-of-mission` / `energy-unlabeled` / `needs-measurement-first` / `scope-too-wide` / `other` |
| What remains possible | Public-tree study, a narrowed model list, or a later inquiry |
| Commercial figure | None. A decline does not include a price |

## Allowed decline / defer classes

- The requested claim would violate [`well-being-alignment.md`](well-being-alignment.md) (certified MTBF, customer logos, invented joules).
- Energy-honesty rows are missing and the sender will not mark them.
- The request treats Models 19–23 gates as field certificates.
- The requested bundle mixes too many unmeasured cards to quote honestly in one pass.
- The work is better done as public-tree study first; defer until a named measurement exists.

## Forbidden classes (on this page and in cover letters)

- Publishing why a named company was declined.
- Inventing a waitlist position, queue length, or response-time SLA.
- Attaching a placeholder price to a decline “to keep the door open.”
- Treating defer as if a packet or change order already exists.
- Claiming Models 19–23 became certified because an inquiry was deferred.

See [`well-being-alignment.md`](well-being-alignment.md).

## Maintainer fill order

1. If completeness is missing, ask the six items first unless the request is already out-of-mission.
2. Name the decision class in one line.
3. Name what the sender can still do in the public tree.
4. Do not write a quote after a decline. A defer may later pass [`inquiry-completeness.md`](inquiry-completeness.md) if the missing rows arrive.

No prices, customers, or SLAs are added by this page.
