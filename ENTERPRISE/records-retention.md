# Records retention after closeout (no prices)

This page lists which files may be **kept or discarded** after a closeout note from [`engagement-closeout.md`](engagement-closeout.md) exists. It is not a records-management product, not a legal hold, and not a claim that any engagement archive already exists.

Companions: [`order-and-contract.md`](order-and-contract.md), [`engagement-closeout.md`](engagement-closeout.md), [`post-quote-packet.md`](post-quote-packet.md), [`licensing-boundary.md`](licensing-boundary.md), [`well-being-alignment.md`](well-being-alignment.md).

## When this page may be used

Only after:
1. The six completeness items were present.
2. A quote following the ten-section outline existed off-repo.
3. The buyer accepted that quote in writing.
4. A packet cover sheet exists.
5. Open change orders were accepted or declined.
6. A closeout note exists that names the final file list and still-open measurement rows.

Until those six are true, the next action is still questions, a quote, a packet, a change order, or closeout — not an archive rule.

## What a retention note must name

| Field | Rule |
| --- | --- |
| Public-tree copies | Stay public; this page does not unpublish cards |
| Private packet files | Kept only if the closeout note listed them |
| Inquiry text | Off-repo; do not paste buyer context into the public tree |
| Energy-honesty rows | Final marks copied from closeout; no silent upgrade |
| Open measurements | Remain `to-be-measured` until a later inquiry restarts the gate |
| Discard list | Named private drafts that will not be retained |
| Commercial figure | Written only on the off-repo retention note — never on this page |

## Allowed retention classes

- Keep the last accepted packet snapshot privately; public cards stay as they are.
- Discard unaccepted draft quotes and unaccepted change-order drafts.
- Keep the closeout note and the completeness checklist off-repo.
- Restart later only through a new inquiry that re-runs the completeness gate.

## Forbidden retention classes (on this page and in cover letters)

- Publishing buyer names, logos, or prices in the public tree.
- Treating host sandbox logs or `gen03_decisions.json` as archived field certificates.
- Relabeling cards 02–20 as licensed weight files because a packet once shipped.
- Claiming a statutory retention period that this repository has not measured or adopted.

See [`well-being-alignment.md`](well-being-alignment.md).

## Maintainer fill order

1. Copy the closeout file list.
2. Mark each private object keep or discard.
3. Confirm no unaccepted change-order draft is stored as if accepted.
4. Write the off-repo retention note. Do not invent a public archive page from it.

No prices, customers, or SLAs are added by this page.
