# Gadgets and Builds

This folder originally contained the off-grid hot water generators and sustainable living biomes documentation.

**Those materials have been moved to a dedicated repository for clearer focus and easier sharing of BOMs and designs:**

→ **[offgrid-hot-water-biomes-gadgets](https://github.com/trigger6980/offgrid-hot-water-biomes-gadgets)**

The dedicated repo contains:
- Three complete generator designs (Solar Thermal, Rocket-Mass Biomass Hybrid, Thermoelectric + PV)
- Detailed sizing, freeze protection, safety guidance, and control sketches
- Bills of Materials orientation
- First concrete Sustainable Living Biome layout

This main portfolio continues to reference and integrate with that work through the energy-aware and Operator AI layers.
