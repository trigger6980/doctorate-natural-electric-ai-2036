# 2036 Agent Skill Set & Authorization Model

## Standing Directive (Every Conversation)
Use all available connectors and skills at any given time, with judicious prioritization of quality of work. Authorize specialized agents (via the skill system) to execute domain work. Goals for the current session must be finished or cleanly checkpointed.

## Authorization Pattern
When a task matches a skill domain, the orchestrator loads that skill, treats it as a specialized agent, executes, verifies, and writes the result back to the repository. Parallel skills may be invoked for independent vertical slices.

## Continuous Improvement
Skills themselves are versioned and upgraded in this folder as 2036 techniques mature (neuromorphic interfaces, physical-AI tool use, formal energy contracts, etc.).
